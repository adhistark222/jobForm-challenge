# Style Guide

## Overview
This document defines the visual and interaction standards for the project requirements form UI. It ensures consistency, usability, and a clean, professional appearance.

---

## 1. Layout

### Structure
- Two-column layout:
  - Left panel: branding/message
  - Right panel: form content

### Left Panel
- Solid primary color background
- Contains a single prominent message
- Centered vertically and horizontally

### Right Panel
- Light background
- Contains all form elements
- Scrollable if content exceeds viewport height

### Spacing
- Vertical spacing between fields: 16px–24px
- Horizontal padding: 24px–32px
- Consistent spacing between sections

---

## 2. Color Palette

### Primary
- Primary Blue: #1F6FA9

### Neutrals
- Background Light: #F5F7FA
- Border Gray: #D1D5DB
- Text Primary: #1f2937
- Text Secondary: #6B7280
- Placeholder Text: #9CA3AF

### Buttons
- Primary Button Background: #1F6FA9
- Primary Button Text: #FFFFFF
- Secondary Action Text: #6B7280

---

## 3. Typography

### Font Family
- Sans-serif (recommended: Inter, Roboto, Helvetica Neue)

### Type Scale
- Main Heading: 28–32px, bold, white
- Section Labels: 14–16px, medium, #333333
- Input Text: 14px, regular, #333333
- Placeholder Text: 14px, regular, #9CA3AF
- Helper Text: 12px, regular, #6B7280

---

## 4. Components

### 4.1 Input Fields
- Height: 40px–44px
- Padding: 10px 12px
- Border: 1px solid #D1D5DB
- Border radius: 8px (0.5rem)

#### Focus State
- Border color: #1F6FA9
- Optional subtle outline or shadow

---

### 4.2 Textarea
- Same styling as input fields
- Minimum height: 160px (10rem)
- Vertical resize enabled

---

### 4.3 Dropdowns
- Same styling as input fields
- Include dropdown caret icon
- Use clear placeholder text

---

### 4.4 File Upload
- Button-style input
- Border: 1px solid #D1D5DB or dashed
- Include helper text (e.g., "Max. 20 MB")

---

### 4.5 Radio Buttons (Budget)
- Circular selection controls
- Label aligned horizontally
- Spacing between options: 12px–16px

---

### 4.6 Buttons

#### Primary Button (Submit)
- Background: #1F6FA9
- Text color: #FFFFFF
- Padding: 10px 20px
- Border radius: 8px (0.5rem)

#### Hover State
- Slightly darker blue

#### Secondary Action (Reset)
- Text-only or minimal styling
- Color: #6B7280

---

## 5. Content Guidelines

### Labels
- Clear and concise
- Sentence case
- Mark optional fields with "Optional"

### Placeholder Text
- Provide examples where helpful
- Example: "For example, '30 Second Radio Spot'"

### Helper Text
- Keep short and informative
- Use only when necessary

---

## 6. Alignment & Consistency

- Left-align all labels and inputs
- Maintain consistent input widths
- Align related fields in the same row (e.g., Country and State)

---

## 7. Accessibility

- Ensure sufficient color contrast (WCAG compliant)
- Provide visible focus states
- Associate labels with inputs
- Do not rely on color alone for meaning

---

## 8. Tone & Voice

- Professional and neutral
- Clear and concise
- Instructional language (e.g., "Select your country")

---

## 9. Responsive Design

- Stack layout vertically on small screens
- Left panel moves above or is hidden
- Inputs become full width
- Maintain minimum touch target height of 44px

---

## 10. Visual Style

- Clean and minimal design
- Strong contrast between panels
- Focus on clarity and usability
